# 과거 마이그레이션 (참고용)

이 앱이 실제 학원에서 굴러가는 동안 **하나씩 쌓인** 증분 마이그레이션들이다.
새로 설치한다면 이 파일들은 **실행할 필요가 없다** — 상위 폴더의 `schema.sql` 이
이것들을 전부 반영한 통합본이다.

그런데도 남겨둔 이유는 두 가지다.

1. **왜 이런 모양이 됐는지가 여기 적혀 있다.** 특히 `supabase-migration-rls-enable.sql` 은
   공개 `anon` 키로 전체 테이블이 열려 있던 상태를 긴급 봉합한 기록이다.
   같은 실수를 안 하려면 그 파일의 주석을 읽어볼 만하다.
2. **이미 구버전으로 운영 중인 DB가 있다면** 개별 마이그레이션이 필요할 수 있다.

⚠️ `supabase-schema.sql`(맨 처음 버전)에는 `disable row level security` 가 들어 있다.
   그건 "혼자 쓰니까 괜찮겠지"라고 판단하던 시기의 산물이고, **틀린 판단이었다.**
   그대로 실행하지 마라.
